☕ API Cafetería El Trigal

API REST para el sistema de gestión de mesas, pedidos y tickets del TPV. Comunicación en tiempo real vía WebSocket.

🔐 Autenticación

GET /api/empleados Listar empleados activos ▶

Retorna todos los empleados activos que tienen PIN configurado. Se usa para mostrar la pantalla de selección de usuario en el login.

Respuesta
Response 200 OK 
[
  {
    "IdEmpleado": 1,
    "Nombre": "María García"
  },
  {
    "IdEmpleado": 2,
    "Nombre": "Carlos López"
  }
]
🧪 Probar
POST /api/login Autenticar con PIN ▶

Valida el PIN de un empleado. Retorna los datos del empleado si es correcto.

Request Body
CampoTipoDescripción
idEmpleado * integer ID del empleado
pin * string PIN de 4 dígitos
Respuestas
Éxito 200 OK 
{
  "success": true,
  "empleado": {
    "id": 1,
    "nombre": "María García"
  }
}
PIN incorrecto 401 
{
  "success": false,
  "error": "PIN incorrecto"
}
🧪 Probar

🪑 Mesas

GET /api/mesas Listar todas las mesas ▶

Retorna todas las mesas (clientes con padre '0002') con su estado actual, incluyendo si tienen ticket activo, número de items y total.

Respuesta
Response 200 OK 
[
  {
    "id": "0003",
    "idCliente": "0003",
    "nombre": "Mesa 1",
    "ocupada": true,
    "idTicket": 1542,
    "numItems": 3,
    "total": 12.50
  }
]
🧪 Probar
GET /api/mesas/en-uso Mesas en uso por empleados ▶

Retorna un mapa de las mesas actualmente abiertas por empleados (bloqueo optimista para evitar que dos camareros editen la misma mesa).

Respuesta
Response 200 OK 
{
  "0003": {
    "idEmpleado": 1,
    "nombre": "María García",
    "desde": "2025-02-06T10:30:00.000Z"
  }
}
🧪 Probar
POST /api/mesas/:idCliente/abrir Abrir mesa ▶

Consulta si existe un ticket activo para la mesa. No crea ticket nuevo, solo retorna el estado actual.

Parámetros de Ruta
ParamTipoDescripción
idCliente * string ID del cliente/mesa (ej: "0003")
Respuesta
Response 200 OK 
{
  "success": true,
  "idCliente": "0003",
  "idTicket": 1542,
  "tieneTicket": true
}
🧪 Probar
POST /api/mesas/:idCliente/ocupar Bloquear mesa para edición ▶

Marca una mesa como "en uso" por un empleado. Retorna 409 si otro empleado ya la tiene abierta. Notifica por WebSocket.

Request Body
CampoTipoDescripción
idEmpleado * integer ID del empleado que ocupa la mesa
nombreEmpleado * string Nombre del empleado
Respuestas
Éxito 200 OK 
{ "success": true }
Mesa ya en uso 409 
{
  "success": false,
  "error": "Mesa en uso",
  "empleado": "Carlos López"
}
POST /api/mesas/:idCliente/liberar Liberar mesa ▶

Libera el bloqueo de la mesa. Solo el empleado que la ocupó puede liberarla. Notifica por WebSocket.

Request Body
CampoTipoDescripción
idEmpleado * integer ID del empleado que libera
Respuesta
Response 200 OK 
{ "success": true }
POST /api/mesas/:idCliente/cerrar Cerrar mesa (limpiar) ▶

Elimina el ticket activo y todas sus líneas de la base de datos. La mesa queda libre. ⚠️ Acción destructiva.

Parámetros de Ruta
ParamTipoDescripción
idCliente * string ID del cliente/mesa
Respuesta
Response 200 OK 
{ "success": true }

📋 Items de Mesa

GET /api/mesas/:idCliente/items Obtener items del pedido ▶

Retorna las líneas del ticket más reciente de la mesa, con nombre del artículo, cantidad y precio.

Respuesta
Response 200 OK 
[
  {
    "id": "CAFE01",
    "nombre": "Café con leche",
    "cantidad": 2,
    "precio": 1.80
  },
  {
    "id": "TOST01",
    "nombre": "Tostada mixta",
    "cantidad": 1,
    "precio": 3.50
  }
]
🧪 Probar
POST /api/mesas/:idCliente/items Añadir producto al pedido ▶

Añade un artículo al ticket de la mesa. Si no existe ticket, crea uno nuevo automáticamente usando el SP pTPV_Crear_Ticket_Comandas. Notifica por WebSocket.

Request Body
CampoTipoDescripción
productoId * string ID del artículo
idEmpleado integer ID del empleado (para crear ticket si es necesario)
cantidad number Cantidad a añadir (default: 1)
Respuestas
Éxito 200 OK 
{
  "success": true,
  "total": 15.30,
  "idTicket": 1542
}
Artículo no encontrado 404 
{ "error": "Artículo no encontrado" }
PUT /api/mesas/:idCliente/items/:itemId/cantidad Actualizar cantidad ▶

Actualiza la cantidad de un artículo en el pedido. Recalcula el total de la línea automáticamente.

Request Body
CampoTipoDescripción
cantidad * number Nueva cantidad
Respuesta
Response 200 OK 
{ "success": true }
DELETE /api/mesas/:idCliente/items/:productoId Eliminar item del pedido ▶

Reduce la cantidad del artículo en 1. Si la cantidad llega a 0, elimina la línea completamente. Notifica por WebSocket.

Parámetros de Ruta
ParamTipoDescripción
idCliente * string ID del cliente/mesa
productoId * string ID del artículo a eliminar
Respuesta
Response 200 OK 
{ "success": true }

🎫 Tickets

POST /api/tickets Procesar ticket de mesa ▶

Busca el ticket existente para un cliente, verifica que tenga items y retorna su información. El ticket ya existe en la BD porque se crea automáticamente al añadir el primer producto.

Request Body
CampoTipoDescripción
idCliente * string ID del cliente/mesa
Respuestas
Éxito 200 OK 
{
  "success": true,
  "IdTicket": 1542,
  "Total": 15.30
}
Sin ticket/items 400 
{ "error": "No hay ticket para este cliente" }

⚡ WebSocket

WS wss://{host}:{port} Eventos en tiempo real ▶

Conexión WebSocket para recibir notificaciones en tiempo real cuando cambian las mesas. Se reconecta automáticamente cada 3 segundos si se pierde la conexión.

Eventos
mesa_actualizada evento 
{
  "tipo": "mesa_actualizada",
  "idCliente": "0003"
}
mesa_en_uso evento 
{
  "tipo": "mesa_en_uso",
  "idCliente": "0003",
  "empleado": "María García",
  "idEmpleado": 1
}
mesa_liberada evento 
{
  "tipo": "mesa_liberada",
  "idCliente": "0003"
}
